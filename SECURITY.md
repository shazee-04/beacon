# Security Policy

## Supported Versions

We actively issue security fixes for the latest version of Beacon on the `main` branch.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| Older releases   | :x:                |

---

## Reporting a Vulnerability

We take the security of **Beacon** seriously. If you discover a security vulnerability, please follow these reporting procedures:

> [!IMPORTANT]
> **Please DO NOT report security vulnerabilities through public GitHub issues.**

### Disclosure Process

1. **Email Report**: Email your report privately to [mgssrangajeewa@gmail.com](mailto:mgssrangajeewa@gmail.com).
2. **Details to Include**:
   - Description of the vulnerability and its potential impact.
   - Steps to reproduce or proof-of-concept code snippet.
   - Affected browser(s) or configurations.
3. **Response Timeline**:
   - We will acknowledge receipt of your report within **48 hours**.
   - We will provide a status update or fix verification within **7 business days**.
4. **Public Disclosure**:
   - After a fix has been tested and merged, we will credit you in the release notes (if desired) and publish a security patch.

Thank you for helping keep Beacon and its users safe! 🛡️
